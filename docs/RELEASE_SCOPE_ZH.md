# 本次独立代码目录的范围

日期：2026-10-04。按作者本轮要求在 `metapli-release/` 整理；原代码目录和论文源文件保留。

| 部分 | 当前范围 |
|---|---|
| 模型 | 通用名称的 MPNN、ANP 及其必要层；严格加载已有模型参数 |
| 数据输入 | 已整理活性／结构记录与既定划分清单的一对一合并、图构建、指纹相似性计算 |
| 上下文检索 | 正文四种方法：FPSimTopK、FPSimNorm、Random、ActivityBased |
| 训练 | ANP 训练目标、全部训练／验证记录及验证集检查点选择 |
| 预测 | 固定模型参数，完整处理指定分区，输出实际上下文、预测及方差 |
| 基础评估 | 完整分区核对、逐靶标 RMSE／R／ρ 及等权汇总 |
| 文档 | 输入格式、环境版本、配置示例、运行命令和软件验证结果 |

本轮独立目录不纳入对照与补充分析、图表生成、基线实验、回放探索、Glide／AF3 调用程序，也不迁入人工候选清单、按测试结果挑选样本／靶标／种子或预测后校正程序。

ActivityBased 是正文规定的已知上下文活性采样策略，仅使用候选上下文标签；查询自身及其标签不参与检索。验证集选择检查点沿用正文训练设置。

数据与模型权重采用后续 Zenodo 归档文件；本目录的配置示例使用通用相对路径。第三方来源的版权和许可保留在 `THIRD_PARTY_NOTICES.md`。
